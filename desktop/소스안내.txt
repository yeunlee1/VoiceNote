버전 1.2.0
VoiceNote Windows 설치형 소스 (이전 이름: 프로젝트 회의록, 1.0.3 소스 ZIP에서 이어짐)

프로그램.cs: 독립 Windows 창, WebView2, 서버 시작·종료 처리 (실행 파일 이름·AppId·자료 위치 %LOCALAPPDATA%\MeetingJournal는 기존과 같음)
앱/화면: HTML·CSS·JavaScript 화면 (회의 준비·녹음·분석·완료 단계, AI 설정 모달, 회의 기록 모달)
앱/서버.cjs: 최초 배포 ZIP에 들어 있던 번들 JavaScript를 수정한 서버. 번들 이전 원본 TypeScript 프로젝트는 제공받지 않았습니다.
앱/AI모델.cjs: 요약 모델 목록과 모델별 출력 상한, 응답 사용량 해석
앱/AI사용량.js: 모델별 AI 사용량 누적 도구 (서버가 /ai-usage.js로 화면에 제공)
앱/프로젝트보관.cjs: 프로젝트 프리셋, 녹음, 회의별 상세 회의내용(notes), 회의록과 AI 사용량(analysis) 보관
앱/프로젝트설정교환.cjs: 프로젝트 설정 파일(voicenote-project-settings 1판, 9칸 중 앱은 1~3번만 사용)의 생성과 검증
앱/체험권한.cjs: 설치 패키지 기본 키의 3회 체험·해제 상태 관리 (체험권한.json은 사용자 자료 폴더에 저장)
앱/출력형식.js: 출력 형식(회의록·핵심 요약·업무 정리·내 형식)의 이름·예시, 내 형식 검증·AI 지시·항목 구성 (서버가 /formats.js로 화면에 제공, 휴대폰 assets/formats.js와 같은 파일)
앱/기본프로젝트.json: 새 설치의 빈 프로젝트 기본값
앱/설치형서버.cjs: 설치형 사용자 저장 경로, 설치 폴더의 기본키.json 연결, 부모 프로세스 종료 처리
설치/빌드.ps1, 설치/설치파일.iss: 실행 파일 컴파일 및 Inno Setup 설치 파일 제작
설치/VoiceNote-심볼.svg, 설치/VoiceNote.ico: 저장소 루트 브랜드VoiceNote.svg·VoiceNote.ico의 사본 (실행 파일·설치 파일·창 아이콘)
앱/*.test.cjs: 자동 테스트

API 키, 회의 기록, 실행 파일, Git 이력, 외부 빌드 의존성은 포함하지 않았습니다.
빌드에는 Windows .NET Framework 4.8, Inno Setup 6, Node v24.18.0 x64 실행 파일, Microsoft.Web.WebView2 1.0.4258.31 패키지 및 WebView2 설치 부트스트래퍼가 필요합니다.
빌드.ps1의 BuildRoot 기본값은 실행할 때마다 프로젝트 안의 산출물\데스크톱\<yyyy-MM-dd-HHmmss> 폴더입니다. NodePath·DependencyRoot 기본값은 현재 PC 경로이므로 다른 PC에서는 인수로 지정하세요. BuildRoot\배포가 이미 있으면 덮어쓰지 않고 멈춥니다.
빌드.ps1의 DefaultKeyFile은 기본값이 비어 있어 지정하지 않으면 기본 키 없이 만듭니다. 체험용 기본 키를 넣을 때만 -DefaultKeyFile로 apiKey JSON 파일을 명시하며, 키는 배포 폴더의 앱기본키.json에만 들어가고 값은 출력하지 않습니다. 소스와 소스 묶음, 구성.json 목록에는 기본키.json이 없습니다.
DependencyRoot 아래에 WebView2 패키지를 WebView2 폴더로 풀고 MicrosoftEdgeWebview2Setup.exe를 놓습니다.
실행 예: .\설치\빌드.ps1 -BuildRoot "D:\VoiceNote빌드" -NodePath "D:\도구\node.exe" -DependencyRoot "D:\VoiceNote빌드\의존성"
테스트 예: node --test 앱/*.test.cjs
