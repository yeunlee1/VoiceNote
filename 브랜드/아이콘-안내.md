# VoiceNote 아이콘

다섯 개의 둥근 음성 막대를 높이와 위치를 달리해 세우고, 막대의 위·아래 끝이 V자를 이루게 한 심볼입니다. 종이, 사각 배경, 글자는 넣지 않았습니다. 바깥 네 막대는 깊은 청록 `#0F7A72`이고 가운데 막대만 밝은 청록 `#22B5A6`입니다. 흰 배경과 어두운 배경 모두에서 보이도록 깊은 청록을 기존 `#0F5457`보다 한 단계 밝게 잡았습니다.

## 파일

| 파일 | 용도 |
|---|---|
| `VoiceNote.svg` | 원본(canonical). 64×64 viewBox, 투명, 사각형 없음 |
| `VoiceNote-작은크기.svg` | 16·24·32px용 단순형. 막대 셋으로 같은 V 실루엣을 유지하고 16·32px 픽셀 격자에 맞췄습니다 |
| `png/VoiceNote-{512,256,48,32,16}.png` | 투명 PNG. 32px 이하는 단순형에서 렌더링했습니다 |
| `VoiceNote.ico` | Windows 다중 해상도(16·24·32·48·64·128·256). 128px 이하는 32비트 BMP, 256px만 PNG입니다 |
| `android/ic_launcher_foreground.xml` | 적응형 아이콘 전경 벡터. 안전 영역(지름 66dp) 안에 들어갑니다 |
| `android/ic_launcher_background.xml` | 적응형 아이콘 배경층. 완전 투명(`#00000000`)이며 앱은 불투명 배경을 넣지 않습니다. 런처가 강제하는 모양 자르기·바탕은 기기 몫입니다 |
| `미리보기/VoiceNote-배경별-미리보기.png` | 흰·어두운·체커보드 배경에서 256/48/32/16px과 확대본을 비교한 그림 |
| `생성.cjs` | SVG를 헤드리스 Chrome 캔버스로 래스터화해 PNG·ICO·미리보기를 다시 만듭니다 (`node 생성.cjs`) |

SVG를 고친 뒤에는 `node 생성.cjs`로 PNG·ICO·미리보기를 다시 만듭니다. 안드로이드 벡터는 SVG의 경로를 그대로 옮긴 것이므로 SVG 경로를 바꾸면 같이 고칩니다.

## 반영할 곳 (플랫폼 담당)

- 데스크톱: `desktop/설치/빌드.ps1`이 지금 아이콘을 코드로 그려 `회의록.ico`를 만듭니다. 이 부분을 `브랜드/VoiceNote.ico` 복사로 바꾸면 `csc /win32icon`, 실행 파일 아이콘(`ExtractAssociatedIcon`), Inno `SetupIconFile`에 같은 아이콘이 들어갑니다. `desktop/설치/VoiceNote-심볼.svg`는 `브랜드/VoiceNote.svg`로 바꿉니다.
- 안드로이드: `mobile/안드로이드/res/drawable/ic_launcher_foreground.xml`, `ic_launcher_background.xml`을 `브랜드/android`의 두 파일로 바꿉니다. `ic_launcher.xml`의 주석(“종이 배경과 파형”)도 새 모양에 맞게 고칩니다.
- 화면 안 로고나 파비콘이 있으면 `VoiceNote.svg`를 그대로 씁니다. 화면 전체 디자인은 바꾸지 않습니다.
